# 👁️ Big Boss: Tech House — Digital Command Center

An interactive, real-time command center web application for **Big Boss Tech House** to manage contestants, tasks, scores, nominations, immunity, evictions, announcements, and timer countdowns with authentic sound effects and microphone broadcasting.

## 🌟 Features Overview (All 12 Mandatory Modules)

1. **Contestant Management:** Track 10+ housemates (*Elon Byte, Ada Lovelace, Linus Kernel, Grace Hopper, Satoshi Nakamoto, etc.*) with team, points, role, avatar, and live status badges (*Active, Nominated, Immune, Captain, Evicted*). Add custom contestants anytime.
2. **Live Leaderboard:** Real-time dynamic standings sorted by points with 🥇 Gold, 🥈 Silver, and 🥉 Bronze rank badges.
3. **Task Management:** Assign tasks across categories (*Development, Hackathon, Security, Luxury*). Completing tasks instantly credits points.
4. **Point System:** Quick `+50` / `-20` buttons plus a modal to add/deduct custom amounts with infraction reasons.
5. **Captaincy System:** Appoint the House Captain with royal coronation fanfare audio, crown badge, and automatic immunity shield.
6. **Nominations:** Nominate contestants with the red alert warning siren.
7. **Immunity Shield:** Grant/revoke immunity with sci-fi shield audio. Immune contestants strictly cannot be nominated.
8. **Danger Zone:** Dedicated monitor displaying all nominated contestants, simulated public vote risk meters (%), and emergency eviction actions.
9. **Big Boss Voice Announcements:** Text-to-Speech AI voice synthesizer, decree broadcast log, and classic Hindi/English Big Boss show catchphrases.
10. **Task Countdown Timer:** Synced countdown timer with presets (*30s, 1m, 2m, 5m, 10m, 15m*), tension ticking, and industrial klaxon timeout buzzer.
11. **House Statistics:** Live telemetry tracking Drama Index (%), Total Points, MVP Leader, Lowest Scorer, and Task Completion Rate.
12. **Eviction Sequence:** Full-screen elimination overlay with suspense heartbeats and doom impact sound effects, moving housemates to the Evicted Hall with wildcard re-entry support.

## 🎙️ Microphone Intercom & Authentic Audio

* **Live Microphone Megaphone:** Broadcast your actual voice live through speakers with authentic Big Boss low-end resonance, PA reverb, and real-time audio waveform VU meter.
* **Speech-to-Text Dictation:** Speak in Hindi or English to automatically transcribe announcements.
* **Authentic Series Sound Effects:**
  * 👁️ Authentic Title Theme (*Bhairav Thaat* flute & sitar riff with timpani boom & whistle glissando)
  * 🔔 Authentic Bronze Temple Gong
  * 🚨 Emergency Nomination Klaxon with heartbeats
  * ☠️ Eviction Doom Impact & Metal Gate Slam
  * 📁 Custom MP3 Uploader (Load any official `.mp3` audio clip from disk)

## 🚀 Getting Started

Simply open `index.html` in any modern web browser (Chrome, Edge, Safari, Firefox):

```bash
# Clone the repository
git clone <YOUR_REPOSITORY_URL>
cd bigboss-tech-house

# Open directly in browser
open index.html
```

Or start a local web server:
```bash
python3 -m http.server 8080
```
Then navigate to `http://localhost:8080` in your browser.
